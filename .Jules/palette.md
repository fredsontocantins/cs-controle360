## 2026-05-22 - [Form Component Accessibility & UX Standardization]
**Learning:** Standardizing accessibility patterns (using `useId` for stable label-input linking, `aria-invalid`/`aria-describedby` for errors) and visual cues (required markers) in base UI components significantly improves the baseline UX of the entire application.
**Action:** Always implement `useId` and proper ARIA error mapping in form-related components like `Input`, `Select`, and `Checkbox` to ensure consistent and accessible behavior across all forms.
