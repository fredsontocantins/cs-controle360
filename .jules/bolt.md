## 2026-08-21 - Report Generation DB Pre-fetching
**Learning:** During management report generation (`ReportGenerator._build_management_report` and `get_consolidated_intelligence`), operational entities (`homologacao`, `customizacao`, `atividade`, `release`) were being queried repeatedly from the database up to 8-11 times per request for cycle window aggregations and playbook inputs. Pre-fetching these lists once at the start of the report generation pipeline and re-using them in-memory eliminated up to 8 duplicate DB roundtrips and drastically reduced latency under load.
**Action:** When calculating sub-summaries or multi-window metrics across the same data source, always pre-fetch full collections once in memory or query at database level rather than invoking `list_entity()` multiple times in the same pipeline.
