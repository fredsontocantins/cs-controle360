## 2026-08-25 - Eliminating Redundant Entity Fetches in Intelligence & Report Hubs
**Learning:** In report generation endpoints (like `/api/reports/intelligence` and `ReportGenerator._build_management_report`), calculating multi-cycle metrics often re-fetches full dataset tables (`list_atividade`, `list_release`, `list_homologacao`, `list_customizacao`) multiple times in a single request. Pre-fetching base datasets once and passing them into windowing and playbook helpers eliminates up to 8 duplicate DB queries per request without changing API contracts or response schemas.
**Action:** When computing summary or report metrics across multiple time windows or sub-services, always check if full operational lists can be fetched once at the top of the handler/service and reused for sub-computations.
