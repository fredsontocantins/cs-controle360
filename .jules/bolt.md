## 2026-10-05 - Avoid Redundant Database Calls in Consolidated Intelligence Endpoints
**Learning:** Consolidating multiple service domains (e.g. PDF Intelligence, Playbooks, and Cross-module aggregations) into a single API endpoint like `/reports/intelligence` often leads to redundant database query calls if each service independently fetches the same underlying documents, activities, or releases.
**Action:** Pre-fetch shared datasets (e.g., `list_documents()`, `list_atividade()`, `list_release()`) once at the router handler level and pass them down into service method helpers (`refresh_application_context(docs=...)`, `build_cycle_audit(docs=...)`). Additionally, reuse pre-parsed document `summary` dictionaries when available to avoid redundant `json.loads` parsing overhead during bulk aggregation.
