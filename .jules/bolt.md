## 2026-05-09 - [Cumulative Dashboard Summary Optimization]
**Learning:** To optimize dashboard summaries, pre-fetching all entity records with `include_history=True` once and performing in-memory filtering is much more efficient than repeated database calls. Pre-calculating expensive operations like datetime parsing (and storing them in a temporary field like `_dt`) and string normalization (e.g., `_owner_label`) once after fetching prevents significant overhead in downstream loops. Adding `@lru_cache` to the core datetime parsing utility further improves performance across the entire application.
**Action:** Use the pre-fetching + in-memory filtering + pre-calculation pattern for any batch processing or summary endpoints. Always consider caching for utility functions used in loops.
