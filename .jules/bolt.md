## 2026-10-11 - Consolidated Intelligence Endpoint Optimization
**Learning:** The `/reports/intelligence` endpoint performed 12 separate database queries per invocation, including duplicate queries for `list_documents()` and `list_atividade()`/`list_release()`. Pre-fetching documents and base lists once and passing pre-fetched data into downstream service methods eliminated redundant DB queries and JSON parsing, yielding measurable latency reductions (~18.8ms -> ~13.7ms). Additionally, `PlaybookGenerator.generate_from_errors` was re-running multi-pass text joining and theme detection across all activities via `_series_frequency`. Replacing multi-pass iteration with direct `Counter` aggregation on pre-grouped items brought `generate_from_errors` runtime down by ~54% (1.220ms -> 0.555ms).
**Action:** When orchestrating aggregated endpoints in routers like `reports.py`, pre-fetch foundational datasets once at the router level and allow service methods to accept optional pre-fetched inputs rather than re-querying the database inside sub-modules.
