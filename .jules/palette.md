## 2026-08-05 - Portuguese ARIA Landmarks and Legacy Code Exclusion
**Learning:** For localized enterprise applications, screen-reader landmarks such as the main sidebar container (`aside`) and the primary navigation links (`nav`) must have localized `aria-label` descriptors (e.g., "Barra lateral", "Navegação Principal") to ensure proper screen reader pronunciation and UX flow. Furthermore, when refactoring a repository with obsolete frontends, always exclude the legacy directory (e.g., `frontend-legacy`) from `tsconfig.json` to prevent TS type-check pollution during automated pre-commit hooks.
**Action:** Always add localized ARIA landmarks to main navigation areas, use `aria-current="page"` to indicate active pages programmatically, and keep configuration lists (like `tsconfig.json` excludes) aligned with renamed legacy folders.
